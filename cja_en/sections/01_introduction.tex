\section{Introduction}
An aerial inspection agent may need to answer whether a building is damaged, how many damaged buildings lie in a region, or where the nearest one is. Descending toward a building can reveal more local detail, but the narrower footprint can hide other buildings needed for a regional answer. The relevant question is therefore whether an additional observation improves the requested assessment, not merely whether an image or a classifier output changes.

Static disaster-image benchmarks hold the image fixed, while aerial navigation benchmarks primarily test movement and target finding. Existing aerial embodied benchmarks already support action-conditioned observations, and remote-sensing agents already support disaster interpretation and structured tool use~\cite{liu2023aerialvln,gao2026openfly,guo2026bedi,zhao2025cityeqa,liu2024rescueadi,thinkgeo2025}. The narrower measurement considered here is whether a fixed geographic question and reference answer can be evaluated under a changing observation footprint while retaining a trace from the executed action to geographic evidence and the answer call. Studying the value of another view therefore requires a fixed task region and answer, a controlled change in observation, and a record connecting the action to perception evidence and the final answer. These requirements can be implemented as image operations, but standardizing them in an episode interface makes the comparison repeatable: a policy request can be distinguished from an executed move, and answer changes can be inspected alongside both view changes and later generation calls.

We present DisasterClaw, an imagery-grounded platform and task benchmark for this question. Paired xBD tiles, building annotations, task regions, and simulated vehicle states are registered to a common map. The benchmark fixes annotation-derived answers on geographic regions while the agent searches or changes its observation footprint. Four task families place different demands on local detail, regional coverage, and geographic reference. A console supports inspection of the scene; the headless runner produces the quantitative episodes.

We use the platform to follow one evidence chain. A development camera ladder first measures how a narrower footprint changes building localization and damage decisions, including both corrections and harms. On the frozen final set of 160 human-reviewed questions from 44 regions in three events, shortcut controls test whether question text or permitted runtime metadata alone can explain task accuracy. A fixed-view matched-call diagnostic then forks every executed T1 recheck: the fixed branch reruns perception and answering on the old image, whereas the changed branch executes the logged recheck. This design separates a changed observation from merely receiving another answer opportunity at the transition level. Complete-policy comparisons remain operating-point measurements rather than estimates of the isolated effect of a new image.

The contributions are:
\begin{enumerate}
\item a georeferenced, ROI-scoped task benchmark in which the reference answer stays fixed as the observation changes, with an explicit boundary between runtime task cues and scoring labels;
\item an inspection interface that records requested and executed actions, rendered views, predicted evidence, answer calls, and terminal outcomes within the same episode; and
\item an empirical characterization of observation value using shortcut controls, fixed-view matched calls, and task-wise help--harm transitions; the accompanying task-conditioned policy is an instantiated operating point rather than the paper's principal contribution.
\end{enumerate}

The platform renders existing orthographic imagery under simplified motion. Its results concern this controlled observation setting and do not measure physical UAV flight.
