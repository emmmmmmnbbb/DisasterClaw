## 1. 目标、范围与完成定义

**目标：用真实无人机多高度影像，检验同一目标区域的低空新观测，相对于高空原图重复判断和高空图裁剪放大，能否改善视觉判断。**

论文定位为独立的补充案例，建议标题为：

> Case study: Re-observation using real UAV imagery

保留现有灾害任务、主实验、模型比较和论文核心结论。本案例优先复用现有视觉语言模型，只做一种简单的“有／无”判断，不新增模型训练，不建设完整仿真器，不以实飞为前置条件。

必须完成的交付物：

1. 可追溯的数据、帧配对和样本清单。
2. 冻结的样本、问题、答案、提示词和三组对照配置。
3. 每个样本的完整原始输出及评分记录。
4. 一份总体与分序列结果汇总，包括纠正和改错情况。
5. 一张代表性对照图、一张论文结果表及一个英文案例小节。
6. 更新后的论文可正常编译，图表与文字中的数字一致。

**完成标准是实验按约定完成并如实报告，不以“真实低空一定优于对照”作为验收条件。** 本轮仅制定计划，不代表已经取得模型结果或完成论文补写。

## 3. 实验设计：先固定最小版本

### 3.1 研究问题与任务

研究问题：在固定地面区域、固定答案、相同模型与调用预算下，真实低空新影像是否提供了超出原图重复判断及数字放大的有效信息？

候选任务：**“标记区域内是否存在停放车辆？”**

选择理由：可以沿用存在性问答形式；不需要灾前影像、损伤等级映射或新增训练。最终能否使用该任务，取决于图像中是否存在足够稳定、可标注的车辆目标。

若车辆运动或类别标注不适合，允许在预实验阶段换成一种有官方标注、跨帧稳定且可见的静态目标类别。只选一种任务，正式实验开始后不根据效果换题。

应用表述使用“无人机目标区域复查”。不将普通车辆存在性判断写成灾损识别、完整应急着陆安全判定或自主飞行验证。

### 3.2 样本与高度

- 先用 `100_0001` 检查流程。进入模型调试的样本全部标记为 pilot，不计入正式结果。
- 优先检查其余五组序列，选择 3–5 组可用序列，每组约 3–5 个固定区域，正式样本目标为 **12–24 个**。
- 12–24 是控制工作量的案例规模，不是经过功效分析得到的统计充分样本量。
- 序列之间如有地理重叠，记录同一地点的组号；预实验和正式实验避免使用同一目标。
- 高、低两个高度层级即可。初始候选为约 100 m 与约 30 m；依据可用帧和共同覆盖范围，在预实验阶段确定并冻结统一选帧规则。
- 每个样本记录实际 `rel_alt`，不把相对起飞点高度未经校正地当成精确离地高度。
- 若低空帧无法覆盖指定区域，先按冻结规则选取能完整覆盖的较高帧；仍不满足则排除该样本并记录原因。
- 不强行凑够数量，不通过大量相邻帧增加样本数；数量不足时缩小为探索性案例并披露限制。

### 3.3 三组对照

每个样本先用高空观测完成第一次判断，然后分别进入三个互不共享后续信息的分支。

| 组别 | 第一次观测 | 第二次观测 | 用于检验 |
|---|---|---|---|
| A：原图重复 | 同一高空图、同一问题 | 原高空图再次提供 | 单纯增加一次判断的效果 |
| B：裁剪放大 | 同一高空图、同一问题 | 从高空原始文件裁出与低空图对应的区域，再缩放至统一输入尺寸 | 同一源图像重新分配像素、集中注意力的效果 |
| C：真实低空 | 同一高空图、同一问题 | 同一地区的真实低空新图，缩放至统一输入尺寸 | 真实新观测相对两种对照的增益或损害 |

正式实验中所有样本都完成三种分支，不只挑选第一次答错的样本。主比较是 C 对 B，C 对 A 作为补充比较。

必须固定的条件：

- 同一模型版本、推理参数、提示词、最大输出长度和图像处理方式。
- 同一地面问题、目标区域和答案；框线样式一致，不通过框的形状泄露答案。
- 同样的两轮推理预算和第一轮历史；第二轮各分支只接收本分支观测。
- 第一轮结果可以保存后复制到三个分支，避免随机的首轮回答差异；记录这是三个逻辑上的两轮分支，而非九次独立评估。
- B 的裁剪使用高空原始文件，不先故意降低其分辨率。B 与 C 尽量对应相同地面范围；映射及残余差异需要记录。
- 不允许向模型提供真值掩膜、答案或带有标签含义的文件名。
- A 保留原图视野，因而与 B/C 的上下文不同；A 是重复判断对照，B 才是区分数字放大与真实新观测的主要对照。

这一步首先检验复查机制。若没有运行自主触发和动作选择策略，不宣称验证了完整智能体的飞行决策。

## 5. 三个推进检查点

### G1：先证明“数据可用”——步骤 3 后

必须满足：

- [ ] 至少一组真实高低空 RGB 能打开，标签可解释。
- [ ] 相同地面目标可对应，指定区域在两幅图中有足够共同覆盖。
- [ ] 实际高度来自元数据，使用含义明确。
- [ ] 可以构造来自高空原始图的合理裁剪对照。

未通过时，优先换同一数据集内的其他序列；不能配对的数据不用于效果比较。暂不投入完整模型评测。

### G2：再证明“流程公平且可运行”——步骤 5 后

必须满足：

- [ ] 三个分支的模型、提示词、调用预算和首轮上下文一致。
- [ ] 模型看不到真值，后续分支之间互不泄露信息。
- [ ] 题目只涉及固定 ROI，跨高度真值不变。
- [ ] 正常输出、无法判断、格式错误和运行错误均有明确处理办法。

G2 不要求低空组表现更好。若三个分支全部答对，照常记录，不以“没有提升”认定流程失败。

### G3：冻结以后再运行正式实验——步骤 6 后

必须冻结：样本 ID、地点分组、帧与 ROI、真值、提示词、模型版本、解码参数、评分规则和故障处理方式。保存协议版本及文件校验值。

若运行后发现确实影响公平性的实现错误，保留旧日志，记录修订原因；必要时对全部受影响样本和分支统一重跑，不只重跑表现不佳的分支。

## 6. 样本与真值制作细则

### 纳入条件

1. 地面 ROI 在高低空帧中可明确对应，目标区域定义不随帧改变。
2. 目标及答案在两次采集间保持稳定；车辆题只纳入可确认未移动的目标。
3. 原图、元数据与标注能配对；答案可以由标注和人工图像核验共同确定。
4. 存在与不存在样本均尽可能包含，并报告实际类别数量；不为凑平衡强行选取含糊样本。

### 排除条件

- 目标运动、出入画面或场景变化导致答案改变。
- ROI 无法可靠对应、关键部分在某个高度完全离开视野。
- 标签冲突、缺失、图像损坏或严重模糊导致真值无法确认。
- 正式样本与用于调试的 pilot 目标重合。

普通尺度变化和部分遮挡是本案例希望覆盖的成像差异，不应一律排除；但必须保证问题所指目标和真值可确定。不能把低空图里没有看到目标，自动解释成地面区域内不存在目标。

每个排除项记录 `sequence_id、frame_ids、roi_id、reason`。人工答案核验应在查看正式模型输出之前完成。

## 7. 运行、资源与错误处理

- 工作目录建议为项目根目录下 `experiments/messi_case/`；这是待创建的组织方案，不表示当前已有脚本。
- 优先复用原论文 Qwen2.5-VL 的既有部署。先确认精确模型 ID、权重版本、量化方式、服务版本和运行设备，再记录到配置。
- 本地运行资源要求沿用既有部署，以 pilot 的实测显存、时延为准；本计划不预设未经测量的 GPU 容量。
- 若使用远程接口，执行前明确服务、发送的公开图像范围和调用预算；本计划不包含实际接口调用。
- 选择尽可能稳定的解码设置，保留模型输出；确定性配置不等于所有运行环境下绝对可复现。
- 第一轮结果复用时，每个正式样本逻辑上有三条两轮分支，实际请求数为 1 次首轮 + 3 次复查，即 **4N**；N=12–24 时为 **48–96 次请求**，不含 pilot、失败重试和可选重复运行。
- 统一输出 `yes / no / uncertain`，允许简短解释。`uncertain` 计为未答对并单独报告，不从分母删除。
- 输出格式无法解析但请求正常完成时，按预设规则标记为无效回答并计入任务失败；不额外调用模型修复答案。
- 网络或服务故障保留错误日志，可按冻结的统一规则重试一次。仍失败时标记运行失败；汇总报告计划样本数、完整配对数及各组失败数，不将故障伪装成缺失样本消失。
- pilot 后确定单请求超时值，例如采用实测常规时延的数倍；记录超时设置。持续异常时暂停批次检查，不无限重试。
- 每条请求落盘后更新进度，保留耗时和运行状态。真实飞行时间、能耗及通信时延没有测量，不能由推理时间替代。

正式命令和依赖版本在步骤 5 形成后写入 README。本计划不提供尚不存在的脚本命令。

## 8. 指标与分析方案

### 必须报告的指标

| 指标 | 定义 | 报告方式 |
|---|---|---|
| 首轮准确率 | 高空首轮答对数 / 评价样本数 | 数量及百分比 |
| 最终准确率 | 各分支第二轮答对数 / 同一评价样本数 | A、B、C 分别报告 |
| 主要差值 | C 最终准确率 − B 最终准确率 | 百分点，同时列出逐样本差异 |
| 补充差值 | C 最终准确率 − A 最终准确率 | 百分点 |
| 纠正数 | 首轮错误、该分支最终正确的样本数 | 数量；纠正率分母为首轮错误数 |
| 改错数 | 首轮正确、该分支最终错误的样本数 | 数量；改错率分母为首轮正确数 |
| 无法判断及异常 | uncertain、解析失败、运行失败分别计数 | 保留各类分母，不混为一项 |
| 分序列／地点表现 | 按原始序列及重叠地点分组重复上述核心统计 | 防止总体结果被一个地点支配 |

分母为零的纠正率或改错率写为“不适用”，不写 0%。有运行失败时，主效应比较使用三组均成功完成的共同样本集，同时报告全部计划请求的完成率；可另外列出把运行失败视为任务未完成的总体结果，明确口径。

### 分析边界

- 同一 ROI 的 A/B/C 是配对数据；同一序列内多个 ROI、相邻帧以及同一地点的重叠序列可能相关。
- 本最小案例以描述性分析为主，不预设显著性检验，也不以 p 值作为完成条件。
- 只有少量地点时，不用大量帧或多次生成伪造较大的独立样本量。若后续扩展到足够多独立地点，再单独制定按地点聚类的不确定性分析。
- 正式输出出现低空无改善或性能下降时，如实报告，并分析视野收窄、遮挡、配准、模型波动等可能因素；这些解释应标明是观察还是推测。
- 单一数据集、少量地点及潜在预训练数据暴露限制了泛化结论。该实验不是未见场景或完整系统外部验证的自动证明。

## 9. 论文落地与图表要求

### 建议正文结构

新增约 500–800 英文词的小节，最终按版面压缩：

1. **目的与数据**：说明它补充真实无人机成像证据；给出实际使用的序列、地点、样本数量与高度范围。
2. **实验协议**：定义固定 ROI、三个分支、模型配置和公平比较条件。
3. **结果**：先报告 C 对 B，再报告 C 对 A；给出纠正和改错数量；结果只能从评分文件生成。
4. **适用范围**：真实采集影像的离线复查；没有实飞闭环，没有新增灾损识别结论。

### 主图

- 内容：同一目标的高空观测、对应高空裁剪、真实低空观测。
- 图中标明：样本 ID、实际高度、固定 ROI、模型输出、参考答案。
- 选择规则：优先展示能说明总体趋势的案例；如存在明显改错或失败，正文或补充材料同时展示。若没有改善，不强行制作“成功案例”。
- 图注说明是离线按高度选取的真实影像，不把排序后的图像写成已验证的连续下降轨迹。
- 尺寸、配色和字体沿用原论文；阅读尺寸下能看清目标及标注。

### 结果表

列出 A/B/C 的答对数、分母、准确率、纠正数和改错数；表注交代序列／地点数量、pilot 排除、错误处理及模型调用预算。分序列结果和完整样本清单可放附录。

### 文稿整合

优先在现有 `shuanglan/polished/` 工作副本中新增小节和本地引用资源，避免顺手改写原始稿件及共享实验统计。构建命令沿用：

```bash
latexmk -pdf -cd -interaction=nonstopmode -halt-on-error shuanglan/polished/main.tex
```

该命令只在实际整合图表和小节后执行。当前文档仅为计划，不需要为 Markdown 修改重新编译论文。

## 11. 排期、替代路线与范围控制

### 建议排期

| 工作日 | 安排 | 当日应得到的结果 |
|---|---|---|
| 第 1 天 | 步骤 1–4；模型环境可并行做准备 | G1 通过，一组可配对图像及 pilot 题目 |
| 第 2 天 | 步骤 5–6 | G2 通过，正式样本与配置冻结，G3 完成 |
| 第 3 天 | 步骤 7–9 | 正式日志、评分表和误差分析 |
| 第 4 天 | 步骤 10–12 | 可放入论文的图表、小节及编译通过的 PDF |
| 第 5 天（缓冲） | 下载延迟、标注争议、必要修正 | 完成复现材料；不用于挑选更漂亮的结果 |

### 遇到问题时怎么处理

| 问题 | 优先处理 | 仍不解决时 |
|---|---|---|
| MESSI 单个压缩包无法下载或损坏 | 换已公开的同类序列，记录缺失情况 | 若一个工作日内仍无可用配对数据，再核查 QuakeCity；不无限等待 |
| 元数据不含完整相机信息 | 对少量近似平面区域进行人工对应或局部配准，记录误差 | 无法确认相同 ROI 的样本不用于主比较 |
| 车辆发生移动 | 排除该候选；在 pilot 阶段检查稳定的其他目标类别 | 冻结前调整一次任务定义；冻结后不按效果换题 |
| 高低空共同区域过小 | 按统一规则选择较高的低空层级或更小固定 ROI | 无法覆盖时排除，保留记录 |
| 正式样本不足 12 个 | 报告实际规模，检查是否尚有未用的合格序列 | 降为探索性案例，不靠相邻帧或重复生成充数 |
| 模型全部答对、没有改善空间 | 如实报告；解释该样本范围未体现复查优势 | 不按结果另挑困难题；更难任务属于另一个事先设计的后续实验 |
| 低空组反而更差 | 保留结果，核查成像与流程原因 | 排除实现错误后，作为机制适用边界讨论 |
| 模型服务不可用 | 确认原论文同版本部署恢复方式 | 先完成数据及协议，模型结果保持“未运行”，不替代成虚构结果 |

### 备用数据的使用边界

- **3DAeroRelief**：现有公开文件说明未确认包含原始 RGB 帧与逐帧相机位姿，不作为本次最小路线的前置工作。不等待作者回复，也不重建完整管线。
- **QuakeCity**：仅在 MESSI 数据配对路线不可用时核查。先确认下载包中的建筑／构件对应关系、帧组织和标签，只有能稳定对应同一对象才设计多视角损伤检查。
- 若改用 QuakeCity，必须更新研究问题、对照和小节定位，说明是**合成航空视角案例**；它无法替代真实航空成像证据。公开资料中的“多视角”不自动意味着可运行交互仿真或提供完整位姿。

### 不纳入本轮的可选增强

中间高度、更多目标类别、自主停止／下降策略、多模型比较、重复生成稳定性实验和真实飞行验证都可后续追加，但不是完成这个案例的条件。若只执行本计划的最小版本，讨论中明确其验证的是观测复查机制。
