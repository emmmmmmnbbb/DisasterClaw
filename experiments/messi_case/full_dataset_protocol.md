# Full-release MESSI 100-to-30-m vegetation replay

This file documents construction of the fixed 409-region cohort and the earlier
Qwen-based perception study. The current single-temporal DisasterClaw
controller experiment with the existing YOLO and SegFormer models is specified
in [`single_temporal_agent_protocol.md`](single_temporal_agent_protocol.md);
its results are the primary MESSI agent replay reported in the manuscript.

This extension uses the author's unpacked 2,525-image MESSI release at
`/home/lc/datasets/MESSI`. The source tree is read-only for this experiment.
The model input and truth manifests are generated by `scripts/prepare_full_messi.py`
in the workspace, with an inventory that checks every image, annotation and
6DOF row for a one-to-one filename match. No model outputs enter selection.

The question is **visible vegetation, including grass, trees and shrubs**.
The two-height action protocol remains a high observation near 100 m relative
to takeoff and one allowed new image near 30 m. Agamim Descend uses the
nearest-to-100 and nearest-to-30 frame in every available sequence. The
previously used `100_0001` sequence remains pilot-only because its images
informed prompt and token-entropy threshold selection. A fixed 24-cell grid
of 760-pixel squares is laid over the low frame. Agamim Paths A--C and Test
IrYamim Path use every 30-m frame and its nearest 100-m frame by GPS, with
a maximum 12-m separation. Each path frame receives the fixed central
760-pixel region. SIFT, ratio matching and RANSAC map the low region to the
high image; at least 40 inliers and an in-bounds high crop are required.

MESSI vegetation mask class 12 supplies a reference only if both mapped
views have at least 5% vegetation (YES), or both have at most 0.5% (NO).
Ambiguous and cross-height discordant cases are excluded. Registration,
distance, out-of-bounds and pilot exclusions are logged individually. The
Test Ha-Medinah Square Path has only 60-m frames and therefore cannot form
a 100-to-30-m pair. The 50- and 70-m path frames remain in the corpus
inventory but are outside this single-action protocol. The 2,525 images
are the complete **source** release, whereas the evaluation denominator is
the set of eligible paired regions after these prespecified rules. Nearby
regions and frames are correlated, so item-level scores are descriptive.

Three isolated second-turn controls reuse each first answer: A repeats the
high image, B gives an original-resolution high-source crop, and C gives
the real lower-altitude crop. A separate paired replay runs the adapted
`AgentVqaController` with the previously defined Qwen YES/NO token-entropy
signal and 0.90 pilot-derived trigger. The hold and agent arms share the
first response. The lower image is read only after the agent's authorized
recheck. This preserves the prior public-sample protocol for the full source
release. It does not reconstruct a flight or run the original ChangeOS
damage perception and presence gate unchanged.

Exact software boundary: the replay imports the repository's unchanged
`AgentVqaController` and `task_conditioned_recheck_decision`. The injected
MESSI environment replaces `perceive_fn`, `vlm_answer_fn` and
`reobserve_fn`; it uses Qwen token entropy instead of ChangeOS damage
probabilities, calls the damage-target branch for this vegetation presence
question, sets the trigger to 0.90, allows one fixed lower frame, and uses
`answer_mode=vlm`, `evidence_level=raw`, and no search. These are substantial
task/configuration adaptations and must be disclosed whenever the replay is
called a DisasterClaw experiment.

An additional gate diagnostic feeds the first fixed-observation VLM answers
through the repository's `AgentVqaController` with the **original presence
question type** passed unchanged to `task_conditioned_recheck_decision`.
Even maximum uncertainty cannot make that gate descend. The diagnostic
reuses existing first model outputs and opens only the high image; it does
not imply that the full original ChangeOS/hybrid disaster pipeline ran on
MESSI. Its first-answer prompt differs from the token-entropy replay, so
absolute accuracies are not a controlled policy comparison.

The `full_descend`, `full_train_paths`, and `full_test_paths` strata are
recorded separately. They must not be pooled with the earlier 12-region
canopy task, which uses a different question and hand-reviewed selection.
