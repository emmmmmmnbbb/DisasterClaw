# 组会周报（2026-07-16）

## 1. 本周要解决的问题

- 明确项目**唯一核心创新**：不确定性驱动的主动复核（UAV 判断不确定时，自主决定是否降高/换角度复核）。
- 其余模块（俯视 VLN 定义、分层规划、语义地图记忆）降级为**支撑核心创新的配套模块**，不再和核心创新平分秋色。
- 借鉴两篇论文思路（双时相变化检测、无人机智能体任务规范化定义），用来**强化"不确定性怎么算得更靠谱"**，不作为独立贡献点。

## 2. 具体改动

1. **文档**：新定位、新增 P5（校准感知）/P6（评测严谨性补丁）阶段及实验清单写入实施计划文档。
2. **数据集**：修复训练集切分漏洞（未见灾害类型混入训练集问题）；新增灾前+灾后配对数据处理流程。
3. **变化感知模型**：新增灾前+灾后双图输入模型，同时输出"是否变化/损伤等级/置信度"，并加入**温度校准**修正模型自信程度。
   - **结构**：Siamese ResNet18 编码器（共享权重），拼接 `[f_pre, f_post, f_post−f_pre]` 后接双头——4 类损伤分类头 + 二值"是否变化"辅助头。
   - **数据**：xBD 灾前/灾后配对标注（`gen_xbd_change_dataset.py`），按建筑 bbox 裁 96×96 patch；训练集 train+tier3 瓦片、验证集 5% 留出、test 933 瓦片、holdout 3 种未见灾害（moore-tornado / nepal-flooding / pinery-bushfire）。
   - **训练**：6 epoch，Adam lr=1e-3，损失 = 损伤 CE + 0.5×变化 BCE；**best val_acc = 0.731**（验证集 4 类损伤 top-1 准确率）。
   - **测试集分类精度**（E10 同批评测，标定前后 Acc 不变）：

   | 子集 | 样本数 | Acc（4 类损伤） |
   |---|---|---|
   | test（同源灾害） | 21,717 | 0.524 |
   | holdout（跨 3 种灾害） | 69,307 | 0.516 |

   - **温度标定**：验证集拟合 **T = 1.668**（>1 说明原模型过度自信）；标定后 ECE ↓39%（test）/ ↓34%（holdout），Acc 不变。
   - **说明**：val_acc（0.731）高于 test Acc（0.524），存在域内/域外差距；且本次训练集未严格排除 holdout 灾种，跨灾害 Acc 是流程演示，非严格泛化结论。
4. **校准评测工具**：新增 ECE/Brier/NLL 等指标脚本，量化校准前后效果。
5. **感知模块**：暴露每类别的概率分布，供复核逻辑使用。
6. **复核决策逻辑（核心改动）**：新增"校准熵阈值"与"信息增益驱动"两种更严谨的复核判断方式，替代原人工经验查表规则；补充"不复核/随机复核"陪跑基线便于对比。
7. **选方向工程改进**：新增打分开关（LLM 打分 + 方位线索 + 探索优先级），定位为次要改进，非核心创新。
8. **自动化测试**：补充新逻辑测试用例，全部通过。

## 3. 实验与结果（E10~E13，共四组，如实汇报）

### E10：温度校准是否真的有效？→ **结论：有效，符合预期**

| 子集 | ECE（未标定→标定） | Brier | NLL | Acc |
|---|---|---|---|---|
| test（同源，n=21717） | 0.276→**0.167**（↓39%） | 0.728→0.653 | 1.706→1.286 | 0.524 不变 |
| holdout（跨灾害，n=69307） | 0.278→**0.182**（↓34%） | 0.738→0.673 | 2.223→1.589 | 0.516 不变 |

标定后 ECE/Brier/NLL 均明显下降，Acc 保持不变（符合"标定只重塑分布形状不改判断"的定义）；跨灾害 holdout 上收益同样成立。**注**：该模型训练集未做严格灾种排除，holdout 结果是"标定流程演示"而非严格泛化实验。

### E11：六种复核策略哪个最好？→ **结论：n=40 样本量太小看不出差异，但查出一个统计口径 bug**

六档（不复核/随机/固定/启发式/校准熵/校准熵+信息增益）两两 SR 差异**全部不显著**（p≥0.49）。关键发现：40 题中仅 **1 题**真正触发过复核（其余 97.5% 全程无受灾证据），导致"复核降低不确定性"指标被平均稀释成 0。修复统计 bug 后，仅看这 1 题：随机复核最差（-0.007），启发式一般（0.001），**校准熵（0.011）与信息增益（0.013）最优**——方向符合预期，但 n=1 只能定性、不能定论，需要证据出现率更高的题库才能验证。

### E12：更聪明的"选方向"能减少绕路吗？→ **结论：无稳定收益，维持"次要改进"定位是对的**

困难任务上几乎无变化，中等难度任务上有小幅提升，跨灾害类型效果不统一，未证实最初"困难任务受益更大"的假设。

### E13：扩大测试规模，结论稳不稳？→ **结论：主结论基本稳，但发现历史遗留的测试集污染问题**

- 跨灾害泛化测试中，检测器在"未见灾害类型"上表现不降反升——查明是训练该检测器时用的是**修复前**的旧数据切分（未见类型未被真正排除），本次测试只验证了新切分流程本身没问题，还不是严格泛化测试；需用新切分重训检测器，留作后续工作。
- 题库从 40 题扩到更大规模后重跑主对比实验，结论方向不变：规划/复核/记忆相关模块均**未能稳定提升最终任务成功率**，进一步支持"核心创新收窄为复核机制"的判断。
