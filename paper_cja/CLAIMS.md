## 当前允许写出的结论

- 把主动复检表述为预算受限的下降--居中，并用有效 GSD 作为可审计量。
- 把当前观测几何写成固定传感器（1024 px）+ 固定视场角（60°）的视场收缩：下限由「恰好一整张瓦片」反推为 443.405 m / 0.50 m/px，巡航为 1330.215 m / 1.50 m/px。
- 写清信息上界仍是源影像 0.5 m/px，不是厘米级低空纹理；这条局限从「人为设定」变成「数据源固有」，但没有消失。
- 写清题目为 ROI-scoped：答案不随高度改变；场景池为巡航 xBD 覆盖 ≥0.80 的 495/4312 张瓦片，并必须披露建成区/条带重叠偏倚。
- 写清灾前通道保持原生 GSD，不随高度降质。
- 写清 Esri World Imagery 仅为非事件当天上下文，不参与 ROI 真值或评分；P1.5 泄漏体检未跑，不得声称源差异已被实验排除。
- 事件不相交切分、功效分析、泄漏断言、模型辅助审核（不得写成纯人工）。
- 温度缩放改善域内 ECE、不改变 argmax（沿用既有校准账本）。
- X1/X2 负结果属于**旧合成模糊阶梯**：400 裁块上巡航↔原生预测翻转 7 次；macro-F1 平坦；
  `accept_native_better=false`，`accept_calibrated_better=false`，oracle 参照差距 0.0094。
  不得把该零结果改写成视场收缩模型的结论。
- **C1/C2 反事实排除实验**：
  1. 训练曲线核查：类别加权交叉熵 + macro-F1 选择重训后，训练集 macro-F1 可达 0.49–0.57，
     排除"分类器从未训练成功"；但事件不相交验证集 macro-F1 全程停留在 0.21–0.25，
     可写"训练内有信号、跨事件不泛化"，不得写成"分类器完全无法学习"。
  2. 标准（非事件不相交）切分基线对标：同一架构在官方标准切分下测试 macro-F1 为 0.31（对比事件不相交 0.22–0.28），
     可写"协议难度解释差距的一部分（约 0.03–0.04）"；到文献 ~0.7 的剩余差距目前只是架构/训练规模的**候选解释**，
     因为轨 B（同架构、事件不相交重训）尚未完成。不得写成已经测过的归因。
  3. H2 架构对比（diff\_attention vs. concat，均类别加权重训）：验证集 macro-F1 concat 略高于 diff\_attention，
     但 diff\_attention 测试集"损毁"类召回更高；可写"未观察到统计显著差异"，不得写"某一架构明显更优"。
  4. 类别加权后"损毁"类召回从 0.007 恢复到 0.16–0.23，可写"类别加权带来部分但不完全的恢复"，
     不得写"类别加权解决了识别问题"或省略"仍远低于随机猜测基线"这一事实。
- **轨 A（leaky）诊断上界**（事件不相交 test，30 张瓦片，数字须能追溯到
  `runs/benchmarks/detector_backends/*.json`）：
  legacy loc F1 0.8068 / damage F1 0.0000 / overall 0.2421 / 轻微与严重召回 0.000；
  xView2 res34/seed0 loc F1 0.8532 / damage F1 0.6304 / overall 0.6973 / 轻微召回 0.5722 / 严重召回 0.4286 /
  逐建筑 macro-F1 0.4069 / 延迟中位 0.220 s。
  允许写「定位接近、差距几乎全在损伤分级」「同样 1024² 输入下中间类可分，裁块尺寸不是坍缩的充分解释」。
  必须全程标注 leaky；不得进入正式对照主表；不得与 legacy 的差值单独归因于架构。
  不得使用方案文档里没有独立 JSON 的 0.4517 / 0.113 s 等数字。
- 部署 checkpoint 已切换为 `strict_diff_attention_seed0_v2.pt`（事件不相交 + 类别加权 + macro-F1 选择 + 加载后现场核验）；
  凡引用 X1/X2/X3/X6/RescueNet 数字必须来自该 v2 checkpoint 的重跑结果（`runs/benchmarks/paper_cja_v2/`），不得混用 v1 与 v2 数字。
- 历史全零成功拆解为三处独立缺陷，均已修复并验证：
  1. LLM 不可达时每步向北（NE≈587.6 m）→ 螺旋搜索；
  2. U-Net 定位器在 256 px 机载视场上零提议（resize 尺度错配）→ 整瓦片原生分辨率定位 + 视场坐标平移；
  3. 判到达半径 35 m > 成功半径 25 m 且停止时不移动 → 判到达后先对准目标再停。
  这三处修复应写成可复现性说明，不得写成独立科学贡献。

  单题 trace 显示 VLM 存在开放词汇误指认（指认位置 61 m 内无 GT 损毁建筑），须如实报告。
- RescueNet 仅为评估域，无灾前配对，差通道恒为 0；结果只能作为域外可用性检查，
  不得单独作为"绑定约束在损伤头"的因果证据。
- X3 oracle 阶梯（200 题事件隔离基准，**旧观测模型**）：L0=0.08 / L1(oracle 指认)=1.00 /
  L2(**已更名为"oracle 初始定位"**，指认模块仍生效)=0.50 / L3=1.00。
  允许写"瓶颈在指认层，导航/运动闭环在指认正确时无损"；不得把 L2 写成"oracle 导航"或"屏蔽指认后的导航能力测试"。
- X6 端到端（**旧观测模型**）：B0–B3 SR 0.07–0.08 同质；五种复检策略 SR 完全相同（0.08），

  "几何投影是必要成分"这一因果表述已被审稿要求撤回，改为报告该条件下的 SR 数字本身，不作因果解释，
  除非配合 Fisher 精确检验的显著性结果。
  B3（HSPM+复检+记忆图）SR 与 B0–B2 同质且 NE 变差，允许写"记忆图作为可开关能力存在，但未验证增益"。

## 禁止主张

- 不得声称校准熵 / 条件期望熵 / conformal 在当前数据上优于随机或不下降。
- 不得把 GSD 阶梯（无论旧合成阶梯还是新视场收缩阶梯）写成已经提供了信息论增益。
- 不得把新观测模型写成已经通过可识别性前置检查；P4 未跑，不得更新 n_flip / n_correctable，不得预设 E4 从分支 C 翻到 A/B。
- 不得把轨 A（leaky）数字写入正式对照主表，或写成在线智能体已经切换到 SOTA。
- 不得把轨 A 与 legacy 的差值单独归因于架构或单独归因于事件曝光。
- 不得声称 Esri/xBD 源泄漏已被实验排除。
- 不得把旧 D6 holdout 当作新系统验证集，也不得因新机制重跑旧 holdout 并挑好看的报。
- 不得把定位 Dice、提议召回写成导航或判断增益。
- 不得把 semSR 写成严格成功。
- 不得把 YOLO 历史账本与 U-Net 账本混用。
- 不得把"损伤头先失败"这一归因写成未经训练/验证曲线支撑的断言；必须引用 \secref{sec:x1train} 的训练曲线证据。
- 不得省略标准切分基线对标结果，单独用事件不相交结果暗示"协议是性能低下的主因"。
- 不得把「剩余差距应归因于架构/训练规模」写成已测量结论（轨 B 未完成）。
- 不得把类别加权后的部分召回恢复（0.007→0.16–0.23）写成"问题已解决"或用于支撑任何下游决策已改善的主张。
- 不得把 diff\_attention 与 concat 的对比写成"其中一种架构显著更优"（H2 无统计显著差异）。
- 不得把 L2 写成"oracle 导航"；必须用"oracle 初始定位"并说明指认模块仍生效。
- 不得把强制退化几何条件的 SR 差异直接写成"几何投影具有因果必要性"，除非补充显著性检验支持。
- 不得把 HSPM / STMR / MemoryGraph / 前端控制台的存在写成"提升了导航成功率"或"机制已被端到端验证"。
  B3 记忆图消融显示 SR 未改善、NE 变差，必须如实报告。
- 不得把系统工程贡献与机制负结果混为一谈，从而弱化负结果或重新引入循环论证（"系统很完整，因此机制成立"）。
- 不得把二维匀速 Mock 运动学写成六自由度飞控、含风扰/避障/电池的航空仿真。
- 不得把 0.5 m/px 的信息上界解释为真实低空厘米级观测。
- 不得继续把巡航/下限写成 30 m / 10 m，除非明确标注为旧观测模型历史记录。
