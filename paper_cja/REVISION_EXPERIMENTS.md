## P0-1　19 事件留一交叉验证（LOEO）

### 问题
全稿最重的结论「跨事件不泛化」建立在 **2 个留出事件**上（val = harvey + mexico-earthquake，test = michael + palu-tsunami）。n=2 无法估计事件间方差。

### 一处与审稿意见不同的判断

review2.md B1 称「表2 标准切分 val macro-F1 在 0.213–0.344 剧烈振荡，振荡幅度大于要测量的全部效应」。
逐行核对 `generated/training_curve_table.tex` 后，这个批评**只对标准切分成立，对核心结论不成立**：

| 配置 | 8 个 epoch 的 val macro-F1 | 极差 |
|---|---|---|
| 差分注意力（事件不相交） | .222 .208 .224 .224 .216 .215 .220 .223 | **0.016** |
| 拼接（事件不相交） | .232 .219 .213 .247 .208 .225 .220 .224 | **0.039** |
| 拼接（官方标准切分） | .213 .310 .213 .318 .294 .344 .333 .325 | **0.131** |

事件不相交的验证曲线**极其稳定**，标准切分才振荡。因此：

- 「训练内有信号（0.49–0.57）、跨事件不泛化（稳定停在 0.22）」这条核心结论**比审稿人给的信用更强**——稳定性本身就是证据
- 真正脆弱的是 **B7 的断言**「协议难度只解释一小部分差距，多数应归因于架构」：它依赖标准切分的单个数字 0.308，而该配置 val 振荡区间为 0.213–0.344，**0.308 落在自己的噪声带内**。0.22→0.31 这个「协议红利」可能不存在

**结论：LOEO 仍要做，但首要目的从「支撑核心结论」变为「拆掉 B7 那条无支撑的归因」。**

### 设计
- 19 个 xBD 事件逐个留出，其余 18 个训练；每折 3 seed（41/42/43），共 57 次训练
- 每折记录：train/val/test macro-F1、逐类召回、各类支持数、**类别先验**
- 输出：19 个 macro-F1 估计 + 事件间方差 + forest plot

### 关键约束
- **每折必须重新拟合温度**，只用该折的训练内验证划分，不得跨折复用
- 记录每折类别先验，用于检验 B1 提到的「事件间类别分布不均衡」是否为混淆因子

### 产物
- `runs/benchmarks/cja_loeo/fold_<event>/metrics.json`
- 新表：事件级 macro-F1 分布（均值 ± 标准差 + 19 行明细，可入附录）
- 新图：forest plot

### 落地后可写
> 19 折留一事件交叉验证下 macro-F1 为 X ± Y；事件间方差是同折内 seed 方差的 N 倍，说明事件身份而非训练随机性是主导误差来源。

## P0-2　多种子重复

### 问题
表1 四行（0.220 / 0.276 / 0.265 / 0.308）各来自**单次训练**，行间差异无法与训练随机性区分。

### 设计
表1 四个配置各跑 3 seed，报告均值 ± 标准差，配对比较用 paired bootstrap。

### 直接后果
若 0.265（事件不相交拼接）与 0.308（标准切分）的 3-seed 区间重叠，**B7 那句「应归因于架构」必须整段删除或反向改写**。这是本实验的主要用途。

## P1-1　X2 换指标重跑（性价比最高）

### 问题
`generated/budget_table.tex` 中 macro-F1 全平（0.277–0.286），但 **ECE 出现 2 倍以上分离**：

| 策略 | macro-F1 | ECE |
|---|---|---|
| 不下降 | 0.279 | 0.086 |
| 随机 | 0.286 | 0.074 |
| 未校准熵 | 0.286 | **0.037** |
| 校准熵 | 0.286 | **0.038** |
| 条件期望熵 | 0.277 | 0.050 |
| Conformal | 0.286 | 0.071 |
| Oracle 参照 | 0.286 | 0.078 |

温度缩放不改变 argmax，所以作用在**概率**上的机制，用只看**标签**的 macro-F1 衡量，天然测不到。`experiments.tex:97` 已点出这一点，但**没有配套度量**。

### 补测指标（均为已有预测的后处理，无需重训）
1. **Brier / NLL**——与 ECE 同族，直接可比
2. **风险–覆盖曲线 + AURC**——回答「概率是否好到能支撑动作选择」，比 ECE 更贴机制
3. **代价敏感风险**——漏报「损毁」的代价 ≫ 误报「完好」；灾害评估本不该等权

### 代价矩阵
建议在附录做敏感性分析（3:1、5:1、10:1 各报一次），**不要钦定单一比值**——否则会被质疑代价矩阵是为出正结果而选。

### 为什么最高性价比
不重训、不改架构、不违反 `CLAIMS.md`（补的是**测量**不是改主张）；有可能把「机制不可识别」变成「定类上不可测、但概率质量上可测且有效」。这是全稿唯一可能翻盘的点。

### 产物
`runs/benchmarks/cja_x2_costsens/` + 新表 + 风险–覆盖曲线图；新增 §5.4「校准侧效应：机制作用在概率而非标签」。

## P1-2　224 px 原生裁块重训

### 问题
当前 **96×96 裁块 @ 0.5 m GSD**，一栋普通民居约占 20×20 px。而「轻微/严重损伤」靠屋顶纹理区分——该分辨率下可能**物理上不可分**。`gsd_class_table.tex` 中轻微（125 例）与严重（12 例）召回双双 0.000。

论文已排除三种竞争解释：从未训练成功 ✅、未处理不平衡 ✅、协议过严 🟡（见 P0-2 告警）。
**输入裁块尺寸是第四种，未被排除。**

### 设计
224×224 原生裁块重训同架构，其余配方不变；与 96 px 版在同一事件不相交切分上对比逐类召回。

### 两种结果都有用
- 中间等级召回显著上升 → 瓶颈是**可分性**而非域偏移，核心归因需改写
- 仍为 0 → 第四种解释被排除，域偏移归因更稳固

**不做的代价**：前三处缺陷都是自己找出来的；第四处被审稿人找出来，性质完全不同。

## P2　ResNet50 + focal loss 单次

### 问题
`experiments.tex:32`、`abstract.tex:11`、`limitations.tex:9` 三处均写「大部分差距应归因于架构/训练规模的局限」。**这是断言，不是测量。**

### 设计
ResNet50 双塔 + focal loss + ≥20 epoch，事件不相交切分，3 seed。

### 两条出路
- 跑 → 「应归因于」有依据
- 不跑 → 三处措辞改为「候选解释之一，本文未做控制实验区分」

**注意**：P0-2 可能先一步让这条断言失效，建议 P0-2 出结果后再决定是否投入 P2。
