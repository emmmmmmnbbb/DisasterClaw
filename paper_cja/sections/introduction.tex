\section{引言}
\label{sec:introduction}

洪涝、地震与野火之后，指挥员更希望对无人机说``检查道路北侧那栋完全损毁建筑''，而不是给出精确坐标。
执行这类指令需要语言条件目标搜索、导航与损伤评估，并且必须承认：第一次俯视观测常常不够。
鸟瞰条件下，小目标、配准误差、类别极不平衡以及卫星--航空域偏移都会使一次性置信判断不可靠。
空天信息处理正从单平台、单模态感知向多模态大模型与智能体赋能的闭环演进：视觉语言大模型把自然语言指令、航拍/卫星影像与结构化感知统一到同一决策回路，智能体据此规划搜索、做出判断并决定是否需要主动复观测。

视觉语言导航（VLN）多在第一人称三维环境中研究\cite{anderson2018vision,liu2023aerialvln}。
灾害测绘则广泛使用地理配准的星载或航拍影像与灾前/灾后配对，如 xBD/xView2\cite{gupta2019xbd}。
空中语言导航近期进一步引入分层语义规划与拓扑记忆\cite{zhang2025citynavagent,gao2024stmr,shah2023lmnav}。
本文连接上述线索，构建一套多模态大模型赋能的空天应急侦察智能体，并在该系统上检验预算受限的主动重观测。
验证出口刻意分层：
把``校准不确定性能否转化为更好的观测分配''放在离线、无导航的预算实验中回答；
把``现有栈在哪一层失败''放在 oracle 阶梯中诊断；
把完整飞行闭环作为现实检验；
把系统本身作为可运行、可复现的工程载体单独陈述（\secref{sec:architecture}），不把模块存在性写成任务增益。
中心机制的形式化（动作集、归一化熵、期望熵减、共形触发）见 \secref{sec:baro}。
观测几何见 \secref{sec:gsd}：下降是视场收缩，不是撤销合成模糊。

本文的贡献归入三个主题：一个可运行、可复现的工程载体（系统、仿真与监控平台）；一个物理自洽的观测几何与预算受限的决策问题；以及一组对负结果的反事实排除与瓶颈分解。前两者是存在性声明，第三者是科学结论，三者之间不得互相推导。

本文贡献如下。
\begin{itemize}
\item \textbf{智能体系统与仿真/监控平台}（工程存在性声明）：双模式编排器（一次性任务规划与闭环语言导航）、分层语义规划与记忆栈、地理配准 xBD 俯视仿真，以及实时人机协同控制台。
这些模块已实现并可复现（\secref{sec:architecture}）。该声明不蕴含导航成功率或重观测增益；尤其禁止把定位 Dice、提议召回或记忆图的存在写成判断/到达改善。
\item \textbf{视场收缩式观测模型}：用固定传感器与固定视场角把高度写成可审计的有效 GSD；下限由``恰好一整张瓦片''反推为 $443\,\mathrm{m}$（$0.50\,\mathrm{m/px}$），巡航为 $1330\,\mathrm{m}$（$1.50\,\mathrm{m/px}$）。
题目锚定 ROI，答案不随高度改变。信息上界仍是源影像原生 GSD，不得解释为厘米级低空观测。
\item 面向航空应急侦察的任务定义：把校准不确定性转为预算受限的下降--居中动作，并以有效 GSD 作为物理可审计量。
\item 离线观测分配实验：在旧合成模糊阶梯、事件不相交裁块上比较校准/未校准/共形/oracle 参照，该构造下预测几乎不随 GSD 翻转、机制主张不可识别。在新视场收缩模型与一个已披露的强感知底座上，降高确实改变证据（逐建筑 $n_{\mathrm{flip}}=733$、$n_{\mathrm{correctable}}=375$），但题目层面净收益为 MARGINAL——机制可测、效应小且不单调。
\item \textbf{重观测的置信标定定位}：在 $160$ 题事件不相交 Agent-VQA 基准上，重观测在 $74/93$ 次中抬升置信度（均值 $0.834\to0.946$），且置信度与正确率大致单调正相关（$0.8$ 档 $21.5\%$、$0.9$ 档 $41.8\%$、$0.99$ 档 $100\%$）。下降不改变``答什么''、只改变``多确定''，据此把重观测的价值从``提高准确率''重新定位为``按置信度可靠弃答''，并量化其过度自信的幅度边界。
\item \textbf{对该负结果的反事实排除与瓶颈分解}：训练/验证曲线核查排除``分类器从未训练成功''，类别加权重训排除``完全未处理类别不平衡''。
一个三方对照把``架构/训练规模不足''与``事件曝光''两个竞争解释分离：同架构事件不相交重训后损伤 F1 仅 $0.017$，现成权重 $0.630$，差距约 $97\%$ 来自事件曝光——即损伤分级坍缩的根源是跨事件泛化，而非架构或裁块尺寸。
\item \textbf{感知底座的角色}：xView2 冠军预训练权重（leaky，其训练划分见过评测事件）在本文中降级为公开披露的感知组件，仅提供真实损伤信号使智能体``有东西可感知''；本文不主张其跨事件泛化，也不把其绝对精度列为贡献。
\item 泄漏安全协议与诊断：事件级切分、功效分析、oracle 阶梯瓶颈归因（指认层，附命名修正）、以及 RescueNet 低空评估域。
端到端历史全零成功的三处实现缺陷排查记录在 \secref{sec:x0x3}，作为可复现性说明而非独立科学贡献。
\end{itemize}
