\section{结论}
\label{sec:conclusion}

本文给出一套面向灾后侦察的语言条件智能体与地理配准仿真/监控平台，并将航空应急侦察中的``再看一眼''写成预算受限的主动重观测，用有效 GSD 把下降变成可测物理量。
系统贡献是工程存在性声明，不改变下述科学结论。
离线分配实验的初步结果是负结果：损伤分类器预测几乎不随 GSD 翻转，校准策略、共形触发与 oracle 参照因此难以在宏观 F1 上区分。
我们没有直接把这个负结果当作结论，而是补做了三组反事实排除实验：训练曲线核查（排除``从未训练成功''）、
类别加权重训（排除``完全未处理类别不平衡''，且确有部分改善——事件不相交测试上``损毁''类召回从 0.007 恢复到 0.16），
标准切分基线对标（把``评测协议过严''与``架构规模不足''分离，显示后者是差距的主要来源）。
三组实验一致指向同一个更精确的结论：\textbf{分类器有能力在训练分布内学到损伤线索，但对事件级域偏移与中间损伤等级的泛化能力不足}，
这是一个真实的、有训练/验证曲线支撑的瓶颈，而不是未经检验的失败归因。
感知校准半题（温度缩放降低域内 ECE、argmax 不变）仍然成立，但不能单独支撑决策主张。
端到端语言条件搜索不再承担唯一验证出口；历史全零成功的三处相互独立实现缺陷（LLM 不可达时探索恒向北、机载视场下定位器零提议、判到达后不对准目标的系统性早停）已全部修复并以单题 trace 与 oracle 阶梯验证，此处作为可复现性说明而非独立贡献。
修复后的 oracle 阶梯把剩余瓶颈压在目标指认层：oracle 指认使严格 SR 从 $0.08$ 达到 $1.00$（SPL $0.986$），
oracle 初始定位（指认仍生效）仅得 $0.50$；在本仿真无风扰/无避障/无能耗约束的运动学假设下，指认正确时闭环几乎无损，但这一结论不外推到真实飞行。
事件不相交协议、功效分析、类别加权训练与标准切分对标是为了让后续正结果站得住。
下一步应尝试更强的类别不平衡技巧（focal loss、两阶段训练、过采样）与更大骨干网络，再重跑 X2；在那之前不应把机制写成已验证的任务增益，也不应把智能体栈的可运行性误读为任务已成功。
