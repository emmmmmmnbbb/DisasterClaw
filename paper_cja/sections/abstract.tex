\begin{abstract}
语言引导的航空应急侦察需要同时完成目标搜索与损伤判定。
本文给出一套已实现的双模式智能体与仿真/监控平台：操作员以自然语言下达任务，系统在地理配准的俯视仿真中闭合感知--规划--执行回路，并提供实时人机协同控制台。
在该平台上，我们将``第一次俯视是否足够''表述为\textbf{预算受限的主动重观测}：用事件不相交训练的双时相损伤分类器给出校准概率，再把证据是否足够转成一次可审计的下降--居中动作，并用有效 GSD 把高度变成可测物理量。
科学问题从导航链条中解耦，在事件不相交的双时相建筑裁块上比较不下降、随机、未校准熵、校准熵、条件期望熵、共形集合以及 oracle 参照。
该机制在当前分类器上\textbf{基本不可识别}，但我们没有止步于此：外部审稿指出``损伤头先失败''这一归因此前从未有训练/验证集证据支撑，
可能只是第四处未被发现的实现缺陷。为此补做训练曲线核查、类别加权重训与公开协议对标三组实验。
结果显示：类别加权训练下训练集 macro-F1 可升至 $0.49$--$0.57$（排除``从未训练成功''），但事件不相交验证集 macro-F1 全程停留在 $0.21$--$0.25$，
是一条干净的``训练内有信号、跨事件不泛化''曲线，构成事件级域偏移的直接证据。
换到官方标准（非事件不相交）切分重训同一架构，测试 macro-F1 从 $0.22$ 升至 $0.31$，
表明协议难度只能解释与文献 $\sim 0.7$ 基线之间差距的一小部分，多数差距应归因于本文架构/训练规模的局限，而非域偏移本身。
类别加权后端到端指标略有改善（``损毁''类召回从 0.007 恢复到 0.16），但仍不足以让任何观测分配策略在宏观 F1 上跑赢随机或 oracle 参照。
端到端历史全零成功被拆解为三处独立实现缺陷（探索恒向北、机载视场零提议、系统性早停）并全部修复；修复后的 oracle 阶梯把剩余瓶颈定位到目标指认层：
oracle 指认使 200 题严格成功率从 $0.08$ 升至 $1.00$，而 oracle 初始定位（指认仍生效，非严格意义的``oracle 导航''）仅得 $0.50$。
本文贡献分两层：可运行的智能体系统与仿真平台是工程存在性声明；可审计协议、经过反事实排除的负结果归因与瓶颈定位是科学结论。
二者不得混读为复检已经提高任务成功率。
\end{abstract}
