\section{Implementation and Reproducibility Details}
\label{app:implementation}

\paragraph{Existing damage model.}
The implemented dual-temporal network uses a shared ResNet-18 encoder and 96-by-96 pre/post building crops.
The baseline concatenates both encoded features and their difference.
The auxiliary change loss has weight 0.5.
The recorded E10 training used six epochs and Adam with learning rate \(10^{-3}\); its learned scalar temperature was 1.668.
These details describe the existing run and will be frozen or explicitly superseded before strict evaluation.

\paragraph{Reinspection controller.}
The controller supports heuristic, entropy-threshold, fixed, random, and information-gain trigger modes.
It deduplicates positions through quantized geographic cells and enforces per-cell and per-episode budgets.
The descend-and-center action is clipped to map bounds and minimum altitude.
Terminal records include confirmed, dismissed, inconclusive, and episode-end states.

\paragraph{Map and memory.}
The semantic map maintains visible area, explored area, landmarks, candidate goals, and surrounding objects in geographic coordinates.
For language-model queries, local cells are serialized as a compact textual grid.
Memory stores observations and outcomes keyed by location.
The hierarchical planner decomposes instructions into landmark-level subgoals before selecting metric waypoints.
These components are held constant in the primary reinspection comparison.

\paragraph{Strict event-disjoint data.}
The frozen replacement split places
\texttt{hurricane-harvey} and \texttt{mexico-earthquake} in validation;
\texttt{hurricane-michael} and \texttt{palu-tsunami} in test; and
\texttt{nepal-flooding}, \texttt{moore-tornado}, and
\texttt{pinery-bushfire} in holdout.
Training uses the twelve remaining events:
\texttt{guatemala-volcano},
\texttt{hurricane-florence},
\texttt{hurricane-matthew},
\texttt{joplin-tornado},
\texttt{lower-puna-volcano},
\texttt{midwest-flooding},
\texttt{portugal-wildfire},
\texttt{santa-rosa-wildfire},
\texttt{socal-fire},
\texttt{sunda-tsunami},
\texttt{tuscaloosa-tornado}, and
\texttt{woolsey-fire}.
The corresponding bitemporal building counts are 143{,}230 / 73{,}859 /
71{,}293 / 69{,}307.
The localization dataset uses the same event partition with pre-disaster
images and binary building masks rasterized from post polygons
(\texttt{/home/lc/datasets/xbd\_loc\_strict\_v1}).
Training entry points reject any non-disjoint manifest when
\texttt{--require-event-disjoint} is set.

\paragraph{Building localization scaffolding.}
The default building proposer is a ResNet34 U-Net trained for eight epochs
on the strict localization split with Dice+Focal loss and ImageNet encoder
initialization only.
Competition champion weights are refused by path guardrails.
Checkpoint:
\texttt{backend/outputs/building\_localization/resnet34\_strict\_v1.pt}.
At inference, pre-event crops yield a building mask; connected components
become boxes; each box is classified by the dual-temporal damage model.
Strict localization metrics are recorded in
\texttt{runs/benchmarks/loc\_metrics.json} and
\texttt{paper/generated/loc\_metrics\_table.tex}.
The YOLO detector under the same split remains a rollback baseline
(\texttt{runs/benchmarks/paper\_strict\_v1/yolo\_metrics.json}).

\paragraph{Evidence-rich reinspection subset.}
The strict reinspection set contains 40 approved single-target episodes
across ten events.
Starts lie outside the 25\,m success radius and inside the default 60\,m
observation radius.
Approval combines contact-sheet inspection with deterministic geometry and
no-data checks; damage severity follows xBD and is not independently
relabeled.

\paragraph{Current evidence ledger.}
Strict event-disjoint calibration uses 71{,}293 test and 69{,}307 holdout building crops.
The retrained dual-temporal checkpoints report best validation accuracy \(0.797\)
with fitted temperatures \(T=1.440\) (concatenation) and \(T=1.483\) (difference attention).
Strict detector metrics are recorded in
\texttt{runs/benchmarks/paper\_strict\_v1/yolo\_metrics.json}.
Strict localization metrics are recorded in
\texttt{runs/benchmarks/loc\_metrics.json}.
Frozen U-Net-proposer navigation and reinspection ledgers live under
\texttt{runs/benchmarks/paper\_strict\_unet\_v1/e1\_nav} (480 episodes) and
\texttt{runs/benchmarks/paper\_strict\_unet\_v1/e11} (720 episodes).
They must not be mixed with YOLO-era episode logs.
The manuscript does not extrapolate localization AP into navigation claims.

\paragraph{Artifacts to release.}
The reproducibility package includes event-disjoint manifests, benchmark instructions, configuration snapshots, checkpoint hashes, per-episode JSONL logs, aggregate scripts, and calibration diagrams.
Generated paper numbers are written by
\texttt{scripts/benchmarks/export\_paper\_assets.py} with source SHA-256 hashes in
\texttt{paper/generated/provenance.json}.
The strict report preserves failed and no-trigger episodes and distinguishes exploratory historical runs from frozen final runs.
